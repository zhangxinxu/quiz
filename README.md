# 前端小测答题收集专用

本仓库用于每周前端小测（JS / CSS / DOM）的题目发布、答案收集与答疑记录。

每期题目于每周四发布在 [Issues](https://github.com/zhangxinxu/quiz/issues) 中（节假日除外，偶尔会忘记），请在对应 Issue 下以评论形式提交答案。

## 答疑形式

每期答疑录制为约1~2分钟的短视频，周末抽时间录制，在抖音“**张鑫旭本人**”和B站“**zhangxinxu**”账号同步更新。

> 早期答疑采用周六10:00-11:00直播+群聊形式，直播地址：https://live.bilibili.com/21193211 ，后改为视频答疑。

## 微信粉丝群

文中的“群聊”指微信粉丝群，想入群可添加微信 zhangxinxu-job，备注“入群”并附上姓名，方便备注（目前2个群已满，需要排队）。

## 积分规则与奖励

答题积分排行榜：https://www.zhangxinxu.com/php/quiz

积分细则如下：

1. 10分制，得分范围为0、2~11分；
2. 当次小测不参与为0分；
3. 每位参与小测人员，至少得2分；
4. 第一位回答人员加1分，因此可能会得到11分；
5. 每次答疑会公布得分要点；
6. 每次答疑之后的回答或修改不算积分；
7. 半年为一个计分周期；
8. 半年积分前三名会有礼品奖励；
9. 解释权归本人所有。
